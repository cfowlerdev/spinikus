### Done ahead of plan

Several **v1** features from the design doc are already in:

- zero-downtime deploys and rollback;
- previews of pull requests;
- build cache cleanup;
- monorepo root directories;
- multiple servers with placement;
- project-wide and environment variables;
- `.env` import and export in the CLI;
- roles on projects and environments;
- the audit log;
- runtime log search and download;
- the command palette.
